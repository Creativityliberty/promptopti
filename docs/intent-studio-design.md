# Nümtema Intent Studio — référence UI

## Direction retenue

Le produit utilise un **Living Intent Canvas** par défaut et ouvre un **Mission Control** seulement à la demande. L’interface transforme une intention brute en carte structurée, propose un assemblage de Skills Nümtema et d’outils MCP, puis compile un Prompt Pack versionné.

## Contrat visuel

- Fond ivoire chaud `#F6F4ED`
- Texte graphite `#252A26`
- Vert forêt `#234333`
- Vert sauge `#789985`
- Vert brume `#DCE8DF`
- Ambre doux `#D79235`
- Rayons de 18 à 28 px selon le niveau de surface
- Ombres diffuses uniquement pour les surfaces flottantes
- Glassmorphism limité au dock de compilation
- Icônes arrondies de 18 à 20 px, trait cohérent
- Conteneurs : rail, canevas ouvert, surface structurée, inspecteur, dock flottant
